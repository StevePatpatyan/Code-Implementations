Java Interpreter and C compiler files taken/adapted from https://github.com/munificent/craftinginterpreters/tree/master


**Before running the test files with the java interpreter, make sure you are in "java" directory and run javac com/craftinginterpreters/lox/*.java to compile the source code.**

**To run interpreter: java -cp . com.craftinginterpreters.lox.Lox**

**Wherever there is an edit in GenerateAst.java, assume it has been compiled and ran to adjust the lox java source code.**
